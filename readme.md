# AI 桌宠软件

一个面向桌面的 AI 伙伴应用。第一阶段聚焦可感知的角色互动、轻量 AI 对话与几项高频桌面工具；角色素材与动作可先使用 Demo 或占位资源，便于尽早验证整体体验。

## MVP 功能范围

### 1. Live2D 桌宠角色

- 使用 Live2D 在桌面展示角色；初期可接入 Demo 模型或占位素材。
- 支持待机状态与基础动作播放，为后续表情、语音和更丰富交互预留扩展空间。
- 角色可在桌面上移动、拖拽和定位。
- 提供两种动作模式：
  - **可移动**：角色可在桌面自由移动。
  - **原地待机**：角色固定在当前位置，仅播放待机或触发动作。

### 2. AI 对话

- 提供可隐藏的聊天窗口，避免长期占用桌面空间。
- 支持使用浮动对话框与角色进行快速、轻量的交流。
- 在设置中配置对话 API，包括 API 地址、模型/服务配置与初始化流程。

### 3. 轻量实用助手

- **番茄钟**：开始、暂停、重置专注计时，并在专注结束时给予提醒。
- **天气**：展示当前位置或用户指定城市的基础天气信息。
- **快速笔记**：快速创建、查看和保存简短笔记。

### 4. 任务栏与设置

- 在系统任务栏（通知区域）提供固定图标，作为应用的主要入口。
- 点击图标可调出设置面板，用于管理应用行为与偏好。
- 设置面板第一阶段包含：
  - 角色选择与切换；
  - 对话 API 配置与初始化；
  - 动作模式切换（可移动 / 原地待机）；
  - 聊天窗口与浮动对话框的显示控制；
  - 番茄钟、天气和快速笔记的基础偏好设置。

## 后续可迭代方向

- 更丰富的 Live2D 动作、表情、音效和角色资源包。
- 对话记忆、人格配置与语音交互。
- 日程、待办和更多桌面效率工具。
- 角色行为的时间、天气或专注状态联动。
