# AI 桌宠软件（SuisuiPet）

半吊子程序员+AI Coding产物，还在学习阶段，有问题欢迎提出或指教！感谢您的包容 > <

## 运行

```bash
pip install PySide6 requests
python main.py
```

- 需要 Python 3.9+（代码用了 `dict[str, Any]`、`X | None` 这类写法，靠 `from __future__ import annotations` 兼容）。
- 桌宠默认出现在屏幕右下角，**右键角色**打开功能菜单，**右键托盘图标**打开设置。
- 对话走 **OpenAI 兼容**接口（默认 DeepSeek），Key 填在「设置 → 角色设置 → API Key」，随角色配置保存在 `data/characters/<角色名>/character.json`。

## 功能与实现进度（截至 2026-09-20）

### 角色与立绘

- ✅ **立绘与动作**：透明背景 PNG 序列帧，窗口按立绘宽高比自适应；`Idle / Move / Talk / Focus / Drag / Think` 六套动作按状态配帧率，缺帧自动降级，找不到立绘则隐藏角色并提示。
- ✅ **桌面表现**：固定 / 自由移动 / 跟随鼠标三种模式（右键「动作」切换，启动默认自由移动），可拖到任意位置，动作频率 1–10 档可调；思考时站着不动。
- ✅ **表情与推理指示**：模型在回复里内嵌 `[开心]` 这类标记更换表情（标记会被剥离，界面只显示正文）；推理模型思考时为 `Think`、正文开始流为 `Talk`。可在「模式设置」关闭或调灵敏度。
- ⬜ 未实现：Live2D 渲染（目前只存配置字段）、语音与音效、更多动作 / 表情资源包。

### 对话与记忆

- ✅ **流式对话**：OpenAI 兼容接口（默认 DeepSeek），回复逐字显示、随时可打断（已生成的部分保留并进入后续上下文）；模型 / 温度 / 上下文轮数 / 角色提示词按角色独立配置。
- ✅ **长期记忆**：会话自动提炼成事实 / 偏好 / 事件 / 约定四类，跨会话记住你说过的事；每条按相关性 × 重要度 × 新鲜度召回，长期不用的自动归档。记忆整理在启动时后台补做。
- ✅ **记忆可查可改**：独立窗口查看 / 编辑 / 删除单条记忆，手动整理，或一键重置。
- ⬜ 未实现：工具调用（天气、时间、窗口视觉）、语音输出（句级切分信号已预留）。

### 助手与界面

- ✅ **番茄钟**：5–120 分钟，浮窗跟随角色，可暂停 / 继续 / 重置，结束时气泡与系统通知提醒。
- ✅ **设置面板**：角色 / 模式 / 工具 / 开发者四页，保存后写入本地配置。
- ✅ **开发者面板**：开启后弹窗查看每次请求真正发出去的消息、token 估算与首字 / 总耗时，用来排查提示词与上下文。

## 立绘素材规范（img 格式）

固定放在角色目录的 `sprites/`，用文件名前缀区分动作：

| 文件名 | 含义 | 帧数 | fps |
|---|---|---|---|
| `Default.png` | 默认立绘，**必需**（缺失则整个文件夹不可用） | 1 | — |
| `Idle1..n.png` | 待机循环 | 2~4 | 4 |
| `Move1..n.png` | 移动 | 4~6 | 8 |
| `Talk1..n.png` | 说话口型 | 3 | 7 |
| `Focus1..n.png` | 番茄钟专注 | 2~4 | 3 |
| `Drag1..n.png` | 拖拽悬空 | 2 | 6 |
| `Happy / Sad / Angry / Surprised 1..n.png` | 表情（整张全身立绘） | 1~2 | 5 |
| `Think1..n.png` | 表情，**同时兼作「思考」动作素材**（模型推理期间播放） | 1~3 | 5 |

- 命名规则为 `<动作名><可选帧序号>`，无序号表示单帧；`_` 开头的文件与目录会被忽略。
- 所有立绘必须**同尺寸且带透明背景**。

## 角色管理

| 操作 | 效果 |
|---|---|
| **添加角色** | 新建 `characters/<名字>/`（含 `character.json`、`sprites/`、`memory/`）；若同名文件夹已存在（之前「断开连接」留下的），直接重新挂载 |
| **导入角色** | 选一个已有的角色文件夹，复制进 `characters/` 并挂载（重名自动加 `-2`） |
| **断开连接** | 只从注册表移除，文件夹完整保留，之后同名「添加角色」即可恢复 |
| **删除数据** | 连同整个角色文件夹（立绘 + 配置 + 记忆）永久删除 |
